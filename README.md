# TraceFort: know your walk-away bid

TraceFort helps first-time buyers in Dallas–Fort Worth and Houston walk into a foreclosure auction knowing the
most they should bid. Answer a short quiz and get your best three homes, each with a walk-away bid that shows its
math, a repair estimate, a risk score, a map and a "ready to bid?" checklist.

Built at **HackUTA 2026** (theme: Homer's *Odyssey*) for the Xome challenge by
[Shramika Rai](https://github.com/SHRAMRAI), [Prajita Gyawali](https://github.com/gyawaliprajita50) and
[Prashna Pandey](https://github.com/forbidynaliew). Not affiliated with or endorsed by Xome.

## What it does

- **Walk-away bid:** starts from what the home is worth once fixed, keeps a cushion for your goal and risk level
  (fix-and-resell uses the investors' 70% rule), subtracts repairs, and leaves room for Xome's buyer's premium
  (5% or $2,500) and ~2% closing. Bid + fees + repairs never go over your budget, and even at your walk-away bid
  the total never costs more than the home is worth (with a 10–25% repair buffer).
- **Investor mode:** picks the set of homes with the most profit after every cost, capped by average risk, with
  no home over half the capital (exact MILP via SciPy; Gurobi if installed).
- **Ask TraceFort:** a Claude-powered helper that explains auctions and *your* homes in plain words (any
  language). An off-topic gate warns on homework, code or prompt-injection *before* the main model is called.
- **Accounts:** first name + 4-digit PIN (PBKDF2), remembered device, lockout after 5 tries, download or delete
  your data. Terms, Privacy, Cookie and Accessibility pages included.

## Data: what's real and what's a sample

- **Real:** home values by ZIP code and bedroom count (Zillow Home Value Index, Sept 2026), ZIP locations
  (U.S. Census), Walmart/Costco locations (OpenStreetMap).
- **Sample:** 2,270 homes (1,227 across 171 DFW ZIP codes, 1,043 across 149 Houston ZIP codes) and their auction
  details. Real auction listings aren't public, so they're generated by fixed, documented rules on top of the
  real values (`generate_data.py`, seed 42). Addresses are deliberately fictional.

## Run it

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Optional secrets in `.streamlit/secrets.toml` (never commit this file):

```toml
anthropic_api_key = "..."   # Ask TraceFort; without it the app uses built-in answers
admin_pin = "..."           # team inbox at /inbox
```

## Checks

```bash
python test_logic.py      # 972 buyer combinations: budget, fees and investor rules
python chatbot.py         # chatbot + scope gate self-checks (no API calls)
python estimates.py       # data self-checks, rebuilds homes.csv / homes_houston.csv
```

## Files

| File | What it does |
|---|---|
| `app.py` | Streamlit site: quiz, homes, map, investor mode, accounts, Ask TraceFort, legal pages |
| `logic.py` | Walk-away bid, screening, ranking, investor optimizer |
| `chatbot.py` | Ask TraceFort (Claude) with scope gate and offline answers |
| `accounts.py` | SQLite accounts, PIN hashing, lockout, contact inbox |
| `generate_data.py`, `estimates.py` | Build the sample homes from real ZIP-code values |
| `site_text.py` | About, How it works, Terms, Privacy, Cookies, Accessibility |

Every number is an educational estimate, not an appraisal, financial advice or a brokerage service.
